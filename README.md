# Synergy

This repository is a signpost to where Synergy is developed:

- **[Deskflow](https://github.com/deskflow/deskflow)**: the upstream community project that Synergy
  is built on. Fixes land there first, so it is the place to report a bug or offer a change.
- **[Synergy Stream](https://github.com/symless/synergy-stream)**: Synergy, taking each change
  straight from Deskflow as it lands. It has no stability guarantee.

## Security

To report a security issue, use
[private vulnerability reporting](https://github.com/symless/synergy/security/advisories/new) on
this repository, never a public issue or pull request. Synergy's published advisories are in this
repository's [security advisories](https://github.com/symless/synergy/security/advisories).
